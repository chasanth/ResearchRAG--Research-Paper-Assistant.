# ResearchRAG – Research Paper Assistant

ResearchRAG is an AI-powered research assistant that uses **Retrieval-Augmented Generation (RAG)** to help users understand and analyse research papers.

## Features

- Upload research papers in PDF format
- Extract and process PDF text
- Split text into chunks
- Generate embeddings
- Store embeddings in a vector database
- Search relevant paper content
- Generate answers using an LLM
- Provide answers with sources
